# English Learning App

Ứng dụng học tiếng Anh xây dựng bằng Flutter, hỗ trợ học từ vựng, luyện tập, đọc và khám phá nội dung học tập.

## Chạy ứng dụng

```bash
flutter pub get
flutter run
```

## Cấu trúc chính

- `lib/features/`: giao diện theo từng tính năng.
- `lib/design/`: catalog và dữ liệu giao diện Figma.
- `assets/`: hình ảnh và font chữ.
